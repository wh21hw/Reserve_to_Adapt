# 共享偏移建簇前初始化：独立优化器消融

声明时已有结果：VisDA共享偏移K7仍将93.81%已知分到新簇；其估计偏移范数0.01138。当前K8 RTA继续原定十轮，不能由中间成绩更改协议。

假设：birth-first产生新簇后，已知分配缺少样本，δ更新失去信息。检验方式是建簇前先在K=0约束下优化已知中心和δ到原有收敛条件，再运行原来的birth-first算法。全部优化同一capped目标，λ、β、κ、τ=R、源划分不变，不用目标标签或新的置信阈值。仅初始化/优化路径改变，不是新增训练损失或真正DP后验。

该阶段并不保证使用真实已知样本：未知也可能被当前已知中心吸收，导致初始化偏差。因此先复用C20源代理的四种固定场景（原始/人工平移，各known-only/mixed），只新增warm-start四次CPU拟合，原共享版结果复用，不重训练网络或重跑旧对照。报告K、已知误建簇、身份准确率、隐藏候选覆盖、δ与收敛。mixed不能仅看K变小；隐藏覆盖下降需保留。未收敛保留失败，不增加迭代或扫描τ。

实现为robust_capacity.fit_robust_capacity的可选shared_shift_warm_start=False，默认旧优化顺序不变。启用时必须已有正shared_shift_precision和可移动中心；初始化使用既有max_steps上限，目标增加或初始化未收敛报错。warm_start_history与后续history分开保存。先做一次新接口功能检查；不得部署覆盖正在使用的核心目录。
