# 共享域偏移：source-only 声明

新版本仅用于独立容量推断，不改变当前VisDA K8/RTA。robust_capacity.py 增加 shared_shift_precision=None，默认保持原目标。启用时锚定项为 Σκ_c||μ_c-a_c-δ||²+τ||δ||²；同一语义仍一个target中心。固定分配下联合解析更新δ与已知中心，不用容易被强先验拖慢的逐坐标近似；候选建簇、noise、β、λ、R及birth-first不变。目标下降检查保留。

运行前冻结：使用已保存C20 source frozen-BN CE3 seed1特征及同seed2026的70/15/15划分；known测试231、hidden原始0..4类51。原source_counts、半径/成本校准全部复用，τ取source参考样本量R，不扫描。以source70%已知训练特征第一主成分为方向，施加0.5√λ的共同平移；方向符号确定，不重新归一化。原始和人工平移两场景，分别全已知及混合池，比较原算法与共享偏移，仅8个廉价CPU拟合，不训练网络。做一次偏移接口定向检查，不重跑既有模型验证。

记录K、已知误建簇率/身份准确率、隐藏候选召回、noise、偏移恢复误差、收敛与目标轨迹。代理已知图参加过encoder监督，人工平移不证明真实域泛化；hidden五类是已有压力块，不宣称新的独立验证集。不得用真实target标签调τ、平移大小或选择方法。结果失败保留，不扩网格。当前尚未执行。

该建模只是层次锚定扩展，非已证明的DP后验；不保证共同偏移可辨识、不保证结构簇是未知语义。正式跨域推断及RTA实验须在代理结果和当前配对训练完整结果后决定。
