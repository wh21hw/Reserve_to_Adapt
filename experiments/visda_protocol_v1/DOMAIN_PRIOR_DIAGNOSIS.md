# 域偏移与源类中心置信度不应混同

只读已保存VisDA K8中心/全量特征，构造48个可行身份接管：把一个已知中心移到现有候选中心位置，删除对应候选槽，其余中心保持。每个候选取目标值最低的已知接管方案，选择不使用目标标签。这不是语义身份验证、优化后合并或重新拟合。

原目标分项：data 4036.461659，birth 261.244584，prior 0.182871。八个候选最优接管的数据项增加0.2096–9.8072，删除一槽节省32.6556，但prior增加2352.9563–6239.6532；总目标增加2323.5795–6210.2764。既有正则化加权均值合并也均不改善full objective；此次对照进一步显示接管target几何主要受到源先验成本阻碍，而非必须保留原已知几何才有好的数据拟合。

解释边界：不能由一个候选接管方案证明正确语义对应，更不能用此标签无关成本宣称恢复真实未知类。证据支持源类计数先验在当前目标下强烈压制跨域中心移动；即使优化器找到更低局部解，该目标仍可能偏好把域结构当新类。

源均值估计误差与跨域偏移应分开：若μ_t=μ_s+δ+ε_c，源样本增多只会减小μ_s的估计误差，不应使ε_c的跨域方差趋零。当前κ_c=源训练类计数相当于强烈依赖同分布假设；单一共同δ不能表达全部类相关域差异。下一模型应提供域不确定性方差下界，而非直接扫描κ或按target标签删除簇。方差如何从可用数据估计尚未解决，不能宣称数据自动确定了全部超参数。

此前domain_balanced弱先验代理吞掉隐藏类，故不盲目推广简单κ缩小。共享偏移真实域也未解决：K7已有较差局部目标，93.8%已知仍误入候选。预建簇优化四源代理指标没有变化。下一步需要既允许合理域移动又保留已知语义身份的建模证据；没有新增损失、模型训练或目标阈值调参。
