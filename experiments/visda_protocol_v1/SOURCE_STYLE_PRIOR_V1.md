# 源风格扰动先验：待执行的候选方案

动机来自实际VisDA接管成本：source count精度把已知中心移动成本推到数千，远高于birth cost 32.66。源均值精确不等于目标均值应不动。简单弱先验已存在C20负结果，故不扫κ系数。

候选层次模型：μ_target,c=μ_source,c+δ+ε_c。源均值估计方差ρ_c/n_c，类别相关域偏移方差ξ_c，两者相加而非把源计数全部当跨域精度。采用各向同性近似时，在当前平方距离目标尺度下κ_c=ρ_c/(ρ_c/n_c+ξ_c)。ξ_c=0恢复源计数；ξ_c>0时，源样本无限增加也不能消除域移动不确定性。

第一种可计算代理是同一冻结源模型下、同一批带标签源图的预声明风格视图。每种风格计算各类中心位移，减去类别等权的共同位移（由已有共享δ承担），余下类相关位移的均方估计ξ_c。严格只用source，图像/label顺序配对；不能用hidden代理标签或real target选风格强度。source_domain_uncertainty.py提供这个数组级估计器，尚不接入默认容量/RTA。

重要限制：该公式下的ξ是源风格压力代理，并非已识别真实目标域方差；风格选择本身是建模假设，不能声称完全消除超参数。删除共同位移会忽略共同平移与类特异偏移的协方差。灰度/亮度变化可能与实际域差异不匹配，结果必须由独立压力池及真实域验证。

计划先在已有C20 source prior提取固定灰度与亮度减半视图，用同一source70%anchor行校准ξ，source15% birth cost和99%半径保持原定义；只改变κ，复用原共享δ=R及候选规则。known-only/mixed、原始/既有人工平移四组代理，不扩风格或系数网格。若隐藏覆盖明显恶化，保留失败，不推广真实域。当前GPU仍完成VisDA K8十轮，不同时启动特征前向；尚无风格特征、κ结果、容量或分类改善。
