# 支持度过滤容量 v1

原始初始IMP（seed1 source3轮）的7个候选期望成员量约为[5,5,1,14,5,31,2]，硬分配数量相同。新增候选合计只约63/564个目标样本；它们不是“已经识别全部未知语义类别”。候选出生受source阈值及域偏移影响，不能用裸簇数宣称真实未知类数。

本轮只改变初始K计数：候选期望成员量 >= source prior_strength(现有值5)才计入K。因此本例K=5。已知中心推断、source99%距离阈值、每轮虚拟方向V（未做支持过滤）、原版门控/自举未知伪标签/损失/预测均不变。不是teacher版本，不采用边缘化预测。支持量与K推断不读目标标签，不扫描支持阈值。

这是借用现有先验强度的工程启发式，不是DP后验占据概率，不把低支持簇认定为不真实，也不保证支持量5的簇是语义类别。新增假设仅为：去掉极低支持候选可能更稳定地估计适配容量。

预算：相同seed1 source checkpoint、A→W、L4，10轮。对照是raw K7自举版本的同预算结果，K2仅作容量背景。报告best/final和机制日志；seed1和best epoch选择均事后，短程结果不证明70轮/跨任务改善。

状态：L4 exec32已完成10轮，K5固定，代码ab07d5b2。teacher与边缘化预测实验均保留，不混称本轮增量。
