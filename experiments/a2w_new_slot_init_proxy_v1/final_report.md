# 结论：直接簇均值初始化未通过已知保护约束

在冻结final70模型的一次缓存反事实中，三个新未知槽均能激活，target共89/564个样本改由它们预测；但是source已知样本97/958被改判unknown，误拒识增加10.13pp，远超事先设定的1pp上限。因此本候选不进入长训练、不作为改进方法保留。

这说明在当前表示上，“给新槽一个簇方向”与“该方向只代表未知”是两件事。尤其已知第2行原有94个source赢家归零；数据方向虽有支持，却可能同时覆盖已有类别。建模未知应同时约束已知重叠，不能只关注K或槽占用。

限制：这不是初始化训练消融，而是epoch10固定聚类成员在epoch70 head输入空间的压力测试；没读目标标签、没测目标准确率、没训练，不能证明真实未知簇数或全部训练机制。新槽方向为实际eval BN→LeakyReLU后的head输入均值，不是把pre-BN特征误当fc输入。

完整证据：`pipeline-results/a2w-new-slot-init-proxy-v1-summary.json`。下一候选需另立实验，不在本批偷偷加入排斥损失或缩放搜索。依据autoresearch单因素与guard规则，标记guard_violation；保留原模型。
