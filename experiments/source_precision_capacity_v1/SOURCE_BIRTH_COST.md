# Source-only 建簇成本探针

这是探索版本，不替换冻结v1，不是DP完整后验。2026-10-04在现有L4上的OfficeHome seed1/C25/source监督3轮冻结特征进行；没有读取target特征或标签。

目标函数只将原来的λK改为βK：λ仍是source类内平方距离99%分位，控制残差截断；β由source已知负样本能产生的最大初始建簇收益校准。已知中心移动、每类source样本数先验、R/N权重、birth-first均保持。β=max(source已知校准集proposal收益)*(1+1e-6)，下界1e-8。它是经验负对照尺度，不保证总体假阳性率；未利用留类回收率挑参数。

每类70%建中心；余下约30%分两半，前半已知样本校准β，后半测试。正对照移除20–24五个类的中心，校准仅用0–19类。注意网络已监督全部25类，这只是留中心几何实验，不是真正从未见过的类别泛化。
